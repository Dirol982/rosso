# Rosso Corsa — сайт СТО в Минске

Живой премиальный сайт автосервиса [Rosso Corsa](https://rosso-corsa.by/) (Минск, ул. Лещинского, 10 и ул. Матусевича, 35к1) в стиле «моторспорт-брутализм» со слоем анимаций.

**Адрес:** https://dirol982.github.io/rosso/

| Страница | RU | EN |
|---|---|---|
| Главная | `index.html` | `en/index.html` |
| Прайс с заказом | `price.html` | `en/price.html` |

## Что на сайте
- Калькулятор «Цена до визита»: 57 работ из прайса клиента, кнопки «Что беспокоит?», заказ-наряд с отправкой в Telegram / Viber / WhatsApp.
- Запись и заказ-наряд как на vagmotors: выбор адреса (Лещинского / Матусевича) и подбор авто «марка и модель → год → двигатель» (`assets/js/cars.js`, ~60 марок, поиск по-русски, по-латински и по коду кузова). У самых массовых моделей точный список двигателей, у остальных — тип топлива или свой текст («1.6 TDI»). Модели нет в списке — пишется как есть.
- Мессенджеры на телефоне открываются прямо в нажатии (Telegram — через приложение, без него — веб-ссылка).
- Прайс с кнопкой «В заказ» и подытогом; заказ общий с калькулятором.
- Проверка гарантии ползунками: 2 000 км или 30 дней, что наступит раньше.
- Светлая и тёмная тема, RU/EN, бегущая строка марок, лента фото с галереей, отзывы из Google.

## Как править
Все тексты, цены, телефоны и отзывы лежат в `tools/build.py`. После правки пересоберите страницы:

```bash
python3 tools/build.py
```

Стили: `assets/css/style.css` (база, токены, светлая тема) и `assets/css/motion.css` (движение).
Скрипты: `assets/js/main.js` (калькулятор, прайс, запись, галерея), `assets/js/cars.js` (подбор авто, данные марок и моделей), `assets/js/tw.js` (тема, сезонная плитка, отзывы), `assets/js/motion.js` (анимации, проверка гарантии).

Хостинг: GitHub Pages из корня ветки `main`, без сборки (`.nojekyll`).
